# Fixtures

Read-only datasets the examples bind with `data name: List<T> from "fixture-name";`. They are **synthetic
illustrative values** made up for the demos, not measurements; `rainfall.json` is twelve plausible monthly
totals in millimetres and makes no claim about any real place.

| fixture | type | used by |
|---|---|---|
| `rainfall` | `List<Number>` | 02, 05 |
| `months` | `List<String>` | 02 |
| `stations` | `List<Point>` | 09 |
| `press-inks` | `List<Color>` | 07, 09 |
